     1→// ============================================================
     2→// LocaBénin — Schéma de données
     3→// SQLite local (sandbox) — migration PostgreSQL/Supabase en production.
     4→// Conventions :
     5→//  - Montants en FCFA : TOUJOURS des entiers (Int), jamais de flottants.
     6→//  - SQLite ne supporte pas les enums Prisma ni Json :
     7→//    les énumérations métier sont des String validées par Zod côté serveur
     8→//    (constantes centralisées dans src/lib/constants.ts).
     9→//  - Soft delete (deletedAt) sur les données utilisateur importantes.
    10→//  - Le contrôle d'accès fin (IDOR) est appliqué dans les routes API :
    11→//    voir docs/DATABASE.md pour la correspondance RLS Supabase prévue.
    12→// ============================================================
