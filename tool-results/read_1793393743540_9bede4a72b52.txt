     5→     5→//  - Montants en FCFA : TOUJOURS des entiers (Int), jamais de flottants.

     7→     7→//    les énumérations métier sont des String validées par Zod côté serveur
     8→     8→//    (constantes centralisées dans src/lib/constants.ts).
     9→     9→//  - Soft delete (deletedAt) sur les données utilisateur importantes.
    10→    10→//  - Le contrôle d'accès fin (IDOR) est appliqué dans les routes API :
    11→    11→//    voir docs/DATABASE.md pour la correspondance RLS Supabase prévue.
